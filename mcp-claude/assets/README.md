# Directory icon

It preserves the original mark and wording without a redesign. The rendered output was inspected for clipping and legibility.

Use this PNG in the directory portal after the owner confirms the asset is approved for this use. The small tagline will be less legible in a thumbnail; the main StockViz mark remains visible. The source is an existing local company asset, not a generated screenshot or a third-party logo.
